# Git Branching & Production Workflow

## 📌 Project Overview

This repository is created for hands-on practice and to further strengthen my understanding of Git branching strategies and production workflows.

It demonstrates practical implementation of feature development, branch management, Pull Requests, merging, bug fixes, hotfixes, and production-related workflows using Git and GitHub.

## 🛠️ Tools Used

- Git
- GitHub
- Git Bash
- VS Code

## 🌿 Workflows Practiced

- Feature Branching
- Development Workflow
- QA Workflow
- PPD Workflow
- Production Workflow
- Bug Fixes
- Hotfix Management

## 🔄 Practical Implementation

- Created and managed multiple branches.
- Worked on feature development (Login, Search, Payment).
- Created and merged Pull Requests.
- Practised bug-fix and hotfix scenarios.
- Worked with development, QA, and production workflows.
- Managed code changes across different branches.

## 📊 Project Highlights

- 10 Pull Requests merged.
- 7 commits pushed to production.
- Multiple feature development and bug-fix scenarios practised.

## 🎯 Purpose

The purpose of this repository is to keep practising real-world Git workflows, improve branching strategy knowledge, and maintain hands-on familiarity with version control practices used in DevOps environments.
